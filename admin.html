1. Connexion GitHub

La sécurité repose sur GitHub, pas sur l’URL de cette page. Elle n’est liée nulle part et les robots sont bloqués, mais une page statique n’est jamais réellement secrète. Le token reste uniquement dans cet onglet.

Permission minimale conseillée : Contents → Read and write, limitée à ce dépôt. Le token est conservé dans sessionStorage et disparaît à la fermeture de l’onglet.
