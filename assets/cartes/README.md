# Cartes historiques

Ces fichiers sont des **fonds cartographiques redessinés pour le jeu** : ils privilégient les entités et frontières de la période plutôt qu’un fond politique contemporain. Ils ne sont pas des fac-similés d’atlas anciens.

Les HTML chargent ces fichiers par chemins relatifs `assets/cartes/...`. Il faut donc conserver cette arborescence sur GitHub.

Les couleurs dynamiques (territoires conquis, perdus, alliés, occupés) restent dessinées par le moteur de chaque jeu au-dessus de ces fonds.
